3.2랜섬웨어의 진화

3.2.1RaaS (Ransomware as a Service)

🔐 RaaS 생태계

랜섬웨어가 서비스화되면서 기술적 지식이 없는 범죄자도 쉽게 공격을 수행할 수 있게 되었습니다:

  • 개발자: 랜섬웨어 제작 및 업데이트
  • 제휴사: 실제 공격 수행 (수익의 70-80% 취득)
  • 액세스 브로커: 초기 침투 경로 판매
  • 협상가: 피해자와 몸값 협상

3.2.2주요 랜섬웨어 그룹

LockBit 3.0

가장 활발한 RaaS 그룹. 자동화된 공격 도구와 빠른 암호화 속도. 2023년 전체 랜섬웨어 공격의 25% 차지.

BlackCat (ALPHV)

Rust로 작성된 크로스 플랫폼 랜섬웨어. Windows, Linux, VMware ESXi 동시 공격 가능.

Clop

MOVEit, GoAnywhere 등 제로데이 취약점 악용. 대규모 공급망 공격 전문.

Black Basta

이중 갈취 전문. 평균 몸값 $2M 이상. 의료, 제조업 집중 공격.

3.4내부자 위협

3.4.1내부자 위협의 유형

👤 내부자 위협 분류

① 악의적 내부자 (Malicious Insider)
  • 금전적 이득을 위한 데이터 절취
  • 경쟁사 이직을 위한 기술 유출
  • 개인적 불만으로 인한 사보타주
② 부주의한 내부자 (Negligent Insider)
  • 피싱 메일 클릭으로 인한 감염
  • 약한 패스워드 사용
  • 민감 정보 무단 공유
③ 타협된 내부자 (Compromised Insider)
  • 계정 크리덴셜 탈취
  • 세션 하이재킹
  • 권한 남용 공격

3.4.2내부자 위협 지표

🔍 행동 기반 탐지 지표
  1. 비정상적인 데이터 접근: 업무와 무관한 파일 대량 다운로드
  2. 시간대 이상: 근무 시간 외 시스템 접속
  3. 권한 에스컬레이션: 승인되지 않은 권한 획득 시도
  4. 데이터 유출 시도: USB, 클라우드, 이메일로 대량 전송
  5. 보안 도구 우회: VPN, Tor 등 익명화 도구 사용

3.5클라우드 보안 과제

3.5.1클라우드 환경의 복잡성

현대 기업의 클라우드 환경은 여러 벤더와 서비스가 혼재된 복잡한 구조를 가지고 있습니다:

클라우드 유형 주요 과제 보안 위험
IaaS 설정 오류, 접근 제어 데이터 노출, 계정 탈취
PaaS API 보안, 데이터 암호화 인젝션 공격, 데이터 유출
SaaS Shadow IT, 데이터 거버넌스 계정 탈취, 규정 위반
멀티클라우드 일관성 있는 정책 적용 가시성 부족, 관리 복잡성

3.5.2클라우드 네이티브 위협

컨테이너 및 쿠버네티스 보안 위협
  • 이미지 취약점: 악성코드가 포함된 베이스 이미지
  • 런타임 공격: 컨테이너 탈출, 권한 상승
  • 설정 오류: 과도한 권한, 네트워크 정책 미적용
  • 시크릿 관리: 하드코딩된 크리덴셜, 평문 저장
  • 공급망 위험: 서드파티 이미지 의존성
